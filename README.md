## Live site

This repository is configured for GitHub Pages at:

`https://shahar-5.github.io/`

If publishing is not active, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

### Before publishing

1. In `index.html`, replace `PASTE_YOUR_N8N_PRODUCTION_URL_HERE` with the production webhook URL.
2. Keep `robots.txt` only if you want the site blocked from compliant search crawlers.
3. Do not upload a CV containing a public phone number or email unless you want those details downloadable.

## Privacy note

The page uses `noindex` metadata, a restrictive `robots.txt`, and JavaScript-based contact reveal. These measures discourage compliant crawlers and basic harvesting, but no public webpage can guarantee that determined automated tools will never collect information shown to visitors.
